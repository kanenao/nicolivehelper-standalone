# NicoLive Recorder

ニコニコ生放送のコメントを自動取得・保存し、視聴画面をローカル録画するWindowsデスクトップアプリです。

**開発版：0.1.0-beta.1**

## β1で実装する機能

- 日本語ダッシュボードとアプリ内バージョン表示
- 放送IDまたは視聴URLを入力してコメント接続
- ニコニコのログイン画面をアプリ内で開く
- 過去コメントの取得とリアルタイムコメント受信
- コメント、ギフト、エモーション、通知、運営コメントを受信時にJSONLへ自動保存
- コメント保存ファイルのCSV書き出し
- Windowsの画面選択でブラウザーの視聴画面を選び、映像・音声をWebMで保存
- コメント取得ライブラリによる自動再接続

## 起動方法

Node.js 22以上をインストールし、このフォルダーで以下を実行します。

~~~powershell
npm install
npm start
~~~

Windows向けインストーラーとポータブルZIPを作成する場合：

~~~powershell
npm run dist:win
~~~

ビルド成果物は dist フォルダーに作成されます。

## 基本的な使い方

1. アプリ上部の「ニコニコにログイン」からログインします。公開番組のコメント取得にはログイン不要の場合もあります。
2. 放送ID（例：lv123456789）または視聴URLを入力します。
3. 「コメント取得を開始」を押します。過去コメントとリアルタイムコメントが受信され、保存フォルダーへ自動追記されます。
4. 映像を残す場合は「視聴ページ」でブラウザーを開き、「録画開始」を押します。
5. Windowsの画面選択でニコ生の視聴画面を選びます。利用可能な場合は共有ダイアログでシステム音声も有効にします。
6. 「録画停止」でWebMファイルを確定します。

## 保存場所

既定の保存先はWindowsの「ビデオ」フォルダー内の NicoLiveRecorder です。

- comments：コメント・イベントのJSONLファイル
- videos：画面録画のWebMファイル

JSONLは1イベント1行で保存するため、長時間配信でも受信のたびに追記されます。コメント画面の「CSVを書き出す」から表計算ソフト向けに出力できます。

## 録画方式と制限

映像・音声はWindowsの画面共有機能とMediaRecorderを使ってWebMとして保存します。HLSの直接取得や暗号化・DRMの解除、視聴制限の回避は行いません。保護された番組や画面キャプチャを制限する番組では、録画できない、映像が黒くなる、音声が含まれない場合があります。画面録画を開始する際は、利用者が対象ウィンドウを選択し、OSの許可操作を行う必要があります。

## コメント取得について

コメント取得にはMITライセンスのNode.jsライブラリ [nicomget](https://github.com/Segu-g/nicomget) を利用します。リアルタイムコメント、バックログ、ギフト等のイベントと再接続機能を利用しています。ニコニコ公式のAPIではなく、配信側の仕様変更により取得できなくなる可能性があります。

NicoLive Recorderはニコニコ（ドワンゴ）の公式アプリではありません。
